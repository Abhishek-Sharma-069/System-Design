 # Backend Engineering Revision Checklist

- [ ] HTTP fundamentals, REST, and API design
- [ ] Authentication and authorization (sessions, JWT, OAuth)
- [ ] Databases: SQL, schema design, indexes, and transactions
- [ ] NoSQL data models and trade-offs
- [ ] Caching strategies and cache invalidation
- [ ] Redis: data structures, caching, persistence, and pub/sub
- [ ] Queues, messaging, and asynchronous processing
- [ ] Kafka: topics, partitions, consumer groups, and delivery semantics
- [ ] Concurrency, parallelism, and race conditions
- [ ] System design: scalability, availability, and fault tolerance
- [ ] Load balancing, proxies, and API gateways
- [ ] Microservices and service communication
- [ ] Distributed systems: consistency, replication, and partitioning
- [ ] Security: input validation, secrets, and common web risks
- [ ] Testing: unit, integration, and end-to-end
- [ ] Logging, metrics, tracing, and alerting
- [ ] Deployment, containers, and CI/CD
- [ ] Reliability: retries, timeouts, rate limiting, and graceful degradation
